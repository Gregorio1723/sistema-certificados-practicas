# Sistema de Gestión de Certificados de Prácticas

## Descripción

Sistema web desarrollado para administrar el proceso de registro, revisión y validación de certificados de prácticas preprofesionales en una institución universitaria.

## Características

- Autenticación de usuarios.
- Gestión de estudiantes.
- Gestión de instituciones.
- Asignación de lugares de prácticas.
- Carga de certificados.
- Validación por administrador.
- Generación de reportes.
- Exportación de datos.
- Envío de notificaciones por correo.

## Tecnologías

- Laravel 12
- PHP 8
- MySQL
- Blade
- CSS
- Vite
